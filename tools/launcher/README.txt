Code ICU · 代码急诊科  v{{VERSION}}
================================================================

把 GitHub 仓库当病人做一次全身体检：算六项生命体征，给一个 0-100 的健康分，
最后开一张《病危通知书》。

在线版：https://gztcode.github.io/code-icu/
项目主页：https://github.com/gztcode/code-icu


----------------------------------------------------------------
怎么用
----------------------------------------------------------------
1. 把本压缩包解压到任意目录
2. 双击 {{LAUNCHER}}
3. 浏览器会自动打开 http://127.0.0.1:8765/
   （若没有自动打开，手动在浏览器地址栏输入这个地址）

停掉服务：关掉弹出的命令行窗口（Windows）/ Terminal 窗口（macOS / Linux）即可。


----------------------------------------------------------------
需要什么
----------------------------------------------------------------
只要一个现代浏览器：Chrome / Edge / Safari / Firefox 均可（需支持 ES Module，
即 2018 年之后的版本）。

启动脚本会优先用 Node.js 起本地服务；没装 Node.js 就自动改用 Python 3。
两者都没有的话，请直接用在线版（功能完全一样，还不用解压）。


----------------------------------------------------------------
端口被占用怎么办
----------------------------------------------------------------
把启动脚本里的 PORT=8765 改成别的数字（比如 8080），保存后重新运行。


----------------------------------------------------------------
为什么不能直接双击 index.html
----------------------------------------------------------------
页面用的是原生 ES Module。Chrome / Safari 在 file:// 协议下会以 CORS 为由拒绝
加载模块脚本（origin 为 null），页面会直接白屏。所以必须起一个本地 HTTP 服务，
启动脚本已经替你做了这件事。


----------------------------------------------------------------
目录说明
----------------------------------------------------------------
  code-icu/     网站文件本体：index.html、css/、js/、icons/ 等

  serve.py      零依赖本地静态服务器（Python 3 版，Node.js 缺失时用）
  {{LAUNCHER}}   启动脚本
  LICENSE       MIT 许可证全文
  README.txt    本文件


----------------------------------------------------------------
数据与隐私
----------------------------------------------------------------
所有体检数据都来自 GitHub 公开 API，由你的浏览器直接向 api.github.com 请求：
不上传任何数据，不经过任何中间服务器。

如果你在页面上填了 GitHub Token，它只保存在本机浏览器的 localStorage 里，
仅用于给 api.github.com 请求加认证头。
