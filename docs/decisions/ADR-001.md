# ADR-001: 采用无构建原生 ES Module 静态站

## Status
Accepted (2026-10-26)

## Background
参赛作品需在 6 天内完成并提交（截稿 2026-11-01 23:59），且需要一个**评委任何时刻点开都能正常运行**的公开体验链接。产品数据全部来自 GitHub 公开 REST API，实测响应头包含 `access-control-allow-origin: *`，浏览器可直连，因此不存在必须引入服务端的理由。

## Decision
采用浏览器原生 ES Module + 原生 CSS + CDN 无关的内联 SVG Sprite，**不引入任何构建步骤与 npm 运行时依赖**。部署产物即源码目录。

## Consequences
**正面**
- 零构建失败风险：没有 `npm install`、没有 bundler、没有版本冲突，部署即复制文件
- 评委点开即跑：无服务端、无数据库、无云函数，不存在「服务器挂了 / 额度用完 / 冷启动超时」
- 迭代最快：改完刷新即生效，6 天窗口内这是决定性的
- 源码可读：评委若想看实现，读源码无障碍

**负面**
- 无 TypeScript 类型检查，需靠 JSDoc 注释与自测弥补
- 无组件框架，视图层需手动组织；单文件 300 行上限要求更严格的模块拆分
- 无 tree-shaking，但本项目体量小，不构成实际影响
